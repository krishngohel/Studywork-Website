01

Grades 6, 7, and 8

Separate grade-level courses for Math, ELAR, Science, and Social Studies, organized around Texas Essential Knowledge and Skills.

02

Practice that teaches

A missed problem reveals a worked example using different values. Students learn the method, then solve the original skill themselves.

03

Individual student profiles

Each learner receives an independent grade assignment, mastery record, accuracy history, and study-session log.

04

Parent dashboard

A protected dashboard manages profiles, course tracks, progress, study time, cloud backup, and the parent PIN.

05

Focused Study Mode

Fullscreen kiosk controls discourage casual app switching while students practice. Windows Assigned Access can provide stronger device-level restriction.

06

Optional cloud backup

Supabase accounts can synchronize profiles and progress across installations. The learning experience remains available when the internet is unavailable.

A clear learning loop

Understand, practice, master.

Studywork rewards consistent understanding instead of one lucky answer.

  1. 1

    Choose a subject and skill

    Students follow grade-level units or continue from their most recent lesson.

  2. 2

    Answer a fresh problem

    Large problem banks provide varied practice across each section.

  3. 3

    Learn from a similar example

    Incorrect answers show an explanation without revealing the answer to the student's problem.

  4. 4

    Build an eight-answer streak

    Eight correct answers in a row mark the skill as mastered.

Local-first by design

Your learning data stays useful—even offline.

Studywork stores student profiles, progress, and study sessions in a local SQLite database. Internet access is not required for everyday practice.

Cloud backup is optional. Parent authentication details are protected by the operating system, and household data is separated with database row-level security.
