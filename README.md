# Studywork Website

The download page for Studywork, a Windows app for Texas grades 6 to 8 practice. It is plain HTML and CSS served by GitHub Pages from `main`.

- Downloads link to `releases/latest/download/<stable name>` on this repo, so a new release never needs a page change. Keep the asset names `Studywork-Setup-x64.exe`, `Studywork-Portable-x64.exe` and `Studywork-universal.dmg`.
- The sizes on the page are written by hand. Update them if a release changes them noticeably.
- The Mac build is an older stand-in until a current one can be built. The page says so.
- `404.html` is served by GitHub Pages for missing paths.
